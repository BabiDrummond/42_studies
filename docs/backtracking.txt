Backtracking essential:
- Choices: Qual as opçoes de escolha para resolver o problema?
- Constraints: Quais são as limitações da escolha (validação)?
- Goal: Chegar no base case.
Observação: Caso a escolha atual falhe na validação, é necessário revertê-la.

Fluxo:
1. Checar base case. Se chegou ao base case, retorna.
2. Iterar pelas possíveis escolhas.
3. Para cada escolha, testar se é válida.
4. Se válida, chamar recursão.
5. Se não, reverter escolha e tentar a próxima.

Parentheses:
Base case: Parenteses estão balanceados
Opções: Substituir parenteses por espaço
Validação: Ainda há a mesma quantidade de pares? Se sim, chamar recursão. Se não, reverter.

Permutations:
Base case: Chegou ao final da string
Opções: Substituir posição por uma das letras fornecidas
Validação: Há caracteres repetidos? Se sim, reverter. Se não, chamar recursão.

Powerset:
Base case: Soma dos elementos é igual a n.
Opções: Números dentro do subset.
Validação: A soma é diferente de N e ainda há elementos no set? Se sim, recursão. Se não, reverter.
